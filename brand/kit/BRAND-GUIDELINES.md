# Margin Brand Guidelines

## 1. The Mark
- **Concept**: Break-Even M (`margin-symbol.svg`)
- **Small-Size Cut**: `margin-symbol-small.svg` (wider datum gap for `16px–24px` browser tabs and favicons).
- **Clear Space**: Keep at least `0.25x` symbol height clear on all sides.
- **Minimum Size**: `16px` square (`margin-symbol-small.svg` / `favicon-16.png`).

## 2. Colour Palette
| Role | Hex | Usage |
| :--- | :--- | :--- |
| **Forest Emerald (Primary)** | `#14532d` | Primary symbol on light backgrounds |
| **Vibrant Emerald (Accent)** | `#059669` | Secondary mono mark, highlights |
| **Deep Void Emerald (Tile)** | `#071b14` | App icon background, dark hero cards |
| **Mint Glow (Reversed)** | `#34d399` | Symbol on `#071b14` dark surfaces |
| **Ink Charcoal** | `#111827` | Wordmark and primary headings |

## 3. Deliverables in `brand/kit/`
- `margin-symbol.svg` & `margin-symbol-small.svg` (master symbols)
- `margin-horizontal.svg` (symbol + wordmark lockup)
- `exports/margin-symbol-{black,white,mono-14532d,mono-059669,square,favicon,app-icon}.{svg,png}`
- `exports/web-icons/` (`favicon.ico`, `favicon.svg`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `maskable-512.png`, `site.webmanifest`, `head-snippet.html`)
- `slides/` (presentation board PNGs with mockups)
